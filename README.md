# Bandezar: przybornik Twojego zespołu

Terminy, piosenki, setlisty, rider, media i wiadomości w jednym miejscu, dla całego zespołu.
Bandezar instaluje się na **Waszym własnym koncie Cloudflare**: dane są tylko Wasze, bez abonamentu za serwer.
Darmowy plan Cloudflare wystarcza jednemu zespołowi z zapasem (baza 500 MB, pliki ok. 5 GB) i nie wymaga karty płatniczej.

## Instalacja (ok. 5 minut, bez programowania)

**Potrzebne:** kod licencji (dostajesz go po zakupie, zaczyna się od `BZ1-`) i adres e-mail.

1. Załóż darmowe konto na **[cloudflare.com](https://dash.cloudflare.com/sign-up)** (wystarczy e-mail, bez karty).
2. Kliknij przycisk:

   [![Zainstaluj Bandezara](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/arkus1972/bandezar-instalacja)

3. Cloudflare poprosi o połączenie z kontem GitHub (darmowe, można założyć w tym samym oknie). Tam zapisze Waszą kopię Bandezara.
4. Nazwy zostaw domyślne i kliknij **Create and deploy**. Po 1–2 minutach dostaniesz adres, np. `https://bandezar.twoja-nazwa.workers.dev`.
5. Otwórz ten adres, wpisz **kod licencji**, nazwę zespołu i swoje imię. Jesteś liderem.
6. Ustawienia → Wspólne dane → **Utwórz zaproszenie**: każdy kolega dostaje swój link. Otwiera go, wpisuje imię i jest w zespole.

**Na telefonie:** otwórz adres w Safari albo Chrome → Udostępnij / menu → **Dodaj do ekranu głównego**. Bandezar działa jak zwykła aplikacja, także bez internetu.

**Drugie urządzenie (np. telefon i komputer):** Ustawienia → Wspólne dane → **Dodaj urządzenie** → otwórz link na drugim urządzeniu w ciągu 15 minut.

**Kalendarz w telefonie:** Ustawienia → Wspólne dane → **Pokaż link do kalendarza** i dodaj go w Kalendarzu Google, na iPhonie albo w Outlooku.

## Bezpieczeństwo
- Wszystko leży na Waszym koncie Cloudflare. Twórca Bandezara nie ma do tego dostępu.
- Bez haseł: wejście kodem licencji (lider) i jednorazowymi linkami (koledzy, kolejne urządzenia).
- Wiadomości w zespole są szyfrowane na urządzeniu (nawet serwer ich nie czyta).
- Kopia zapasowa: Narzędzia → Kopia zapasowa (plik z całym zespołem i plikami).
